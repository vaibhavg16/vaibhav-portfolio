about

From support tickets to infrastructure

I'm a Linux and DevOps engineer based in Nashik, India, moving from a year of hands-on technical support into infrastructure and automation work. That year at Aress Software put me in front of real Linux environments daily — troubleshooting, ticket resolution, and keeping systems running — and it's what pointed me toward DevOps as a career.

Since then I've been building out the toolkit: Docker and Kubernetes for containers and orchestration, Git & GitHub Actions for version control and CI/CD, and steadily deeper Linux administration. I document the process publicly in a 90 Days of DevOps series on GitHub, and I'm currently working through Terraform and cloud infrastructure on AWS.
